# 学习系统UI-skill

用于生成或扩展「AI 自主学习系统」移动端小程序页面的 Codex skill。

## 适用场景

- 学习首页、待办计划、历史计划、课程推荐
- 登录、手机号验证、首次信息补全
- 制定计划流程、学习信息填写、日期选择弹层、错误态
- 每日学习计划、课程任务卡、日历计划、空状态

## 使用方式

将本目录放入 Codex skills 目录后，在相关任务中使用 `学习系统UI-skill`。

生成完整页面前，先阅读：

`references/ui-style-guide.md`

它包含画布、色彩、字体、组件、状态、文案和检查清单。
